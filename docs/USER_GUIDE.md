# دليل المستخدم — المحترف

هذا الدليل هيكل مبدئي وسيُستكمل مع تنفيذ كل وحدة.

## البداية
عند اكتمال وحدة الإعداد الأولي، سيُطلب إنشاء PIN للمالك وضبط بيانات المركز والعملة.

## العملاء والأجهزة
سيتمكن المالك من تسجيل العميل وبيانات الاتصال والعنوان، ثم ربط جهاز أو أكثر به مع النوع والماركة والموديل والرقم المسلسل.

## الصيانة
كل طلب صيانة يحصل على رقم تذكرة مستقل، وقناة خدمة (داخل المركز أو زيارة منزلية)، وسجل حالات وتشخيصات ومرفقات.

## الفواتير والتحصيل
الفاتورة الصادرة لا تُعدل بصمت. التصحيح يتم بسند تعديل/مرتجع أو إجراء موثق. يمكن تسجيل دفعات جزئية ومتعددة.

## النسخ الاحتياطي
سيُنشأ ملف مشفر قابل للنقل. احتفظ بكلمة مرور النسخة منفصلة؛ فقدانها قد يجعل استعادة الملف مستحيلة.

## ليلى
الاتصال بمزود AI اختياري، وقد يترتب عليه استهلاك مدفوع من حساب API الشخصي. لا ترسل بيانات عميل قبل الموافقة.
